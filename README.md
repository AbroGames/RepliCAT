# RepliCAT

RepliCAT - дельта-репликация обычных C# объектов без внешних сериализаторов.
- **Сервер** для объекта и его базовой копии (baseline, последнее отправленное состояние) пишет `byte[]`, в котором только изменившиеся члены с `[Replicated]`
- **Клиент** применяет эти байты к **существующему** объекту, присваивая члены. Объект не пересоздаётся

Сеть, спавн/деспавн корневых объектов и обход объектов в конце кадра библиотека не делает - это задача вызывающего кода.
Ссылки между сетевыми сущностями передавай через NetId (`int`/`long`), а не ссылками на объекты.

Все типы лежат в пространстве имён `RepliCAT` (`RepliCAT.Bits` - `BitWriter`/`BitReader`, `RepliCAT.Codecs` - кодеки).

## Зависимости
- .NET 10
- `GodotSharp` 4.7.1 - структуры Godot (`Vector2`, `Color`, ...) и их кодеки
- `Serilog` 4.3.0 - логирование предупреждений

Тесты лежат в `RepliCAT.Tests` (xUnit) и запускаются через `dotnet test` в корне репозитория.

## Атрибуты
- `[Replicated]` - на поле или свойство (любой видимости, в том числе в базовом классе). Для автосвойства можно `[field: Replicated]`
  - `Tolerance = x` - значение считается изменившимся, только если максимальная разница по компонентам с последним отправленным больше `x`
  - `Manual = true` - член не сравнивается автоматически, отправляется только при полной синхронизации и после `ManualReplication.MarkDirty(owner, nameof(Member))`
- `[Quantize(precision)]` - квантование без границ: `round(v / precision)` как varint, размер зависит от величины
- `[Quantize(min, max, precision)]` - квантование с границами: фиксированное число бит, значения вне диапазона и NaN прижимаются к границам (с одним предупреждением в лог на член)

`Quantize` и `Tolerance` работают для `float`, `double`, `Vector2`, `Vector3`, `Vector4`, `Quaternion`, `Color` и целых до `long`.
На члене-коллекции они применяются к элементам-значениям (у словаря - к значениям, не к ключам). К множеству их применить нельзя: его элементы сравниваются точно.

Что можно реплицировать:
- значения: примитивы, `string`, перечисления, `Nullable<T>`, структуры Godot (`Vector2/3/4(I)`, `Color`, `Quaternion`, `Rect2(I)`) и всё, для чего зарегистрирован кодек (`replicator.Codecs.Register<T>(...)`)
- вложенные объекты (классы), в том числе полиморфные через `ITypeIdMapping` (реализацию отображения типов предоставляет вызывающий код)
- `ReplicatedList<T>` и `ReplicatedDictionary<TKey, TValue>`, в том числе с объектами и другими коллекциями внутри. Члены элементов отслеживаются по отдельности
- `ReplicatedSet<T>` - множество значений (как ключи словаря): передаются только добавленные и удалённые элементы

`List<T>`, массивы, `Dictionary<,>` и `HashSet<T>` не поддерживаются - построитель модели выдаст ошибку с подсказкой.

```csharp
public class Unit
{
    [Replicated] public int Id;
    [Replicated, Quantize(-512, 512, 0.01)] public Vector2 Position;
    [Replicated(Tolerance = 0.25)] public float Energy;
    [Replicated] public Stats Stats;                                   // вложенный объект
    [Replicated] public readonly ReplicatedDictionary<int, Buff> Buffs = new();
    [Replicated, Quantize(0, 100, 0.5)] public ReplicatedList<float> Path = new();
    [Replicated] public readonly ReplicatedSet<string> Tags = new();
    [Replicated(Manual = true)] public string Description;

    [Replicated] public int Hp { get => _hp; set { _hp = value; OnHpChanged(); } } // сеттер вызовется на клиенте
    private int _hp;
}
```

## Сервер
```csharp
var replicator = new Replicator(typeIds, logger: logger); // один на все объекты, не потокобезопасен
ReplicationBaseline baseline = replicator.CreateBaseline(unit); // при спавне

// Конец кадра: одна дельта на объект, общая для всех клиентов
if (replicator.TryWriteDelta(baseline, out byte[] delta))
{
    SendToAllClientsReliable(unit.Id, delta); // baseline уже обновлён, данные обязаны дойти
}

// Manual-член изменили - пометь его до конца кадра
unit.Description = "...";
ManualReplication.MarkDirty(unit, nameof(Unit.Description));
```
Много объектов можно писать в один пакет: `TryWriteDelta(baseline, BitWriter writer)` дописывает дельту в общий писатель
(если ничего не изменилось, писатель не трогается), а клиент читает объекты по очереди через `Apply(target, ref BitReader reader)`.

## Клиент
```csharp
var replicator = new Replicator(typeIds, logger: logger);
var unit = new Unit(); // создаётся при спавне, дальше только обновляется
replicator.Apply(unit, delta);
```

## Снимок для нового клиента
```csharp
// Можно в любой момент кадра, даже посреди изменений
if (replicator.TryWriteSnapshot(baseline, out byte[] snapshot))
{
    SendReliable(newClient, snapshot); // затем новый клиент получает те же дельты, что и все
}
// false - дельта для объекта ещё ни разу не писалась, новый клиент получит объект с первой дельтой
```
Снимок строится из базовой копии, а не из живого объекта, поэтому "снимок + любая следующая дельта" всегда согласованы.
Исключение - manual-члены: они пишутся из живого объекта, так что новый клиент получает их текущее значение.

## Рукопожатие
`replicator.GetSchemaHash(typeof(Unit))` - хэш формата данных типа. Сравни хэши сервера и клиента при подключении.
Хэш описывает объявленные типы членов, но не подтипы полиморфных членов: сравнивай хэши всех типов из `ITypeIdMapping`.
Само отображение типов должно совпадать у сервера и клиента: одинаковые типы с одинаковыми id на обеих сторонах.

## Контракты
- Транспорт должен быть **надёжным и упорядоченным** (например, reliable-канал ENet или reliable RPC). Базовая копия одна на объект, и дельта считается относительно последней отправленной
- После того как `TryWriteDelta` вернул `true`, данные **обязаны** дойти до всех клиентов: базовая копия уже обновлена
- Если `TryWriteDelta` бросил исключение, писатель откатывается, а базовая копия сбрасывается. Следующая дельта запишет всё и восстановит клиентов
- Реплицируемые коллекции на клиенте нельзя менять локально и нельзя разделять между членами: идентификаторы слотов принадлежат серверу
- Кодеки, зарегистрированные после построения модели типа, на эту модель не влияют. Регистрируй кодеки сразу после создания `Replicator`

## Исключения
- `ReplicationFormatException` - повреждённые или несовместимые данные. При модели без ошибок конфигурации (см. ниже) случайные байты дают только это исключение, а чтение ограничено лимитами и размером входа
- `ReplicationException` (базовый класс) - ошибка конфигурации с путём к члену в сообщении: неподдерживаемый тип члена, подтип без `ITypeIdMapping`, строка длиннее лимита и т.п. На клиенте она тоже возможна:
  - члену без сеттера (get-only свойство, `readonly` поле) нужен новый экземпляр объекта или коллекции (у клиента `null`, другой runtime-тип или сервер прислал `null`)
  - у создаваемого типа нет конструктора без параметров
- Если `ITypeIdMapping.GetType` бросает исключение или возвращает `null`, это ошибка формата: id пришёл из сети
- `Apply` не атомарен: после исключения объект может быть обновлён частично. Такого клиента нужно синхронизировать заново снимком

## Подводные камни
- **Сеттеры.** Для поля значение просто присваивается. Если нужны побочные эффекты при получении, вешай `[Replicated]` на свойство. Сеттер члена-значения вызывается при каждом получении, сеттер объекта или коллекции - только если изменилась ссылка (клиент создал новый экземпляр или получил `null`)
- **Любой класс без кодека считается вложенным объектом.** Член типа `Node`, `object` или `IList<T>` станет объектом с пустой моделью или потребует `ITypeIdMapping`. Для ссылок на сущности используй NetId, коллекции объявляй как `ReplicatedList<T>`/`ReplicatedDictionary<,>`/`ReplicatedSet<T>`
- **`MaxDepth` (по умолчанию 64) считает и объекты, и коллекции.** Список объектов тратит два уровня на элемент, поэтому дерево `Node { ReplicatedList<Node> Children }` при лимите 64 может быть глубиной около 32. Цикл ссылок на сервере даёт `ReplicationException`, а не переполнение стека
- **`MaxCollectionCount` (по умолчанию 65536)** ограничивает число элементов и идентификаторы слотов. Память получателя на список пропорциональна этому лимиту. Слоты переиспользуются, но если список внутри кадра вырос выше лимита, живые элементы могут остаться в слотах за лимитом, и запись будет бросать исключение до `Clear`
- **Погрешность квантования.** С границами реальный шаг равен `(max - min) / steps`, где `steps = round((max - min) / precision)`, так что `min` и `max` представимы точно, а ошибка меньше `precision` (до ~0.75·`precision`), а не `precision / 2`. Без границ ошибка - `precision / 2`. Изменение меньше кванта не отправляется, медленный дрейф отправится, когда пересечёт границу шага
- **Границы `float`.** Границы атрибута - `double`, поэтому `1.1f` больше `1.1`: значение на самой границе может дать одно ложное предупреждение о выходе из диапазона
- **Допуск.** С `Tolerance = x` клиент может отставать от сервера на величину до `x`
- **`long` с `Quantize`/`Tolerance`** идёт через `double` и теряет точность выше 2^53, без границ прижимается к ±2^62. Не используй их на идентификаторах. Без атрибутов `long` передаётся точно
- **Ключи словаря и элементы множества** должны иметь кодек (объекты как ключи запрещены), `null` ключом быть не может. Кодек ключа обязан быть без потерь, а ключ-класс с пользовательским кодеком - сравниваться по значению (`Equals`/`GetHashCode`), иначе клиент молча разойдётся с сервером. Структуры-ключи без `IEquatable<T>` упаковываются при каждом сравнении
- **Manual-члены.** Manual-объект или коллекция делают manual всё поддерево: изменения внутри не отправляются, пока не помечен сам член. Пока член не помечен, новый клиент может видеть более новое значение, чем старые клиенты, поэтому помечай каждое изменение до конца кадра. Ошибка записи manual-члена (например, слишком длинная строка) проявится при снимке, то есть при подключении клиента. `Tolerance` на manual-члене не действует. `MarkDirty` помечает члены по имени, так что одноимённые члены базового класса и наследника помечаются вместе
- **Перечисления** без `[Flags]` и без отрицательных значений пишутся минимальным числом бит по максимальному объявленному значению, остальные - полной шириной базового типа. Новое максимальное значение может изменить число бит, а с ним формат и хэш схемы
- **Строки** ограничены 64 КиБ UTF-8 (`StringCodec`), одиночные суррогаты заменяются на U+FFFD
- **Godot double precision** (`REAL_T_IS_DOUBLE`) кодеками Godot не поддерживается, они рассчитаны на `real_t = float`
- **Логгер.** Без логгера `Replicator` пишет через глобальный логгер Serilog (`Log.ForContext<Replicator>()`), поэтому настрой `Log.Logger` или передай свой логгер в конструктор. Вне движка (например, в юнит-тестах) не используй логгеры, которые вызывают `GD.*`: такой вызов вне Godot роняет процесс
- **Производительность.** Неизменённые объекты при записи дельты память не выделяют. Снимки выделяют (одноразовые тени manual-членов), но они редки
